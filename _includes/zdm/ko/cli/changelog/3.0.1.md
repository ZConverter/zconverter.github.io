#### v3.0.1

보안 업데이트 릴리스입니다. **커맨드 · 옵션 · 출력 형식 · 종료 코드는 v3.0.0 과 같습니다.** 스크립트는 수정할 필요가 없고, 실행 파일만 교체하면 됩니다.

> **v3.0.0 이하를 쓰고 있다면 교체를 권장합니다** — v3.0.0 이하 실행 파일에는 아래 보안 패치가 적용되지 않은 Node.js 22 가 들어 있습니다.

---

**보안 — 내장 Node.js 를 22 에서 24.22.1 로 교체**

- 실행 파일에 들어 있는 Node.js 런타임을 **v22.21.1 → v24.22.1** 로 올렸습니다. 2026-10-21 Node.js 보안 릴리스의 패치가 반영된 버전입니다.
- CLI 는 ZDM 서버 응답을 받을 때 Node.js 내장 HTTP 클라이언트를 사용하며, 압축된 응답(`content-encoding: br`)을 이 런타임이 풉니다. 이 해제 과정의 취약점(CVE-2026-111497)이 이번 교체로 해소됩니다.
- 지원 OS 범위는 v3.0.0 과 같습니다 — Linux x64(CentOS 7 · RHEL 7 이상, glibc 2.17+), Windows x64.
- 배포 파일 크기가 Linux 약 44 MB → 약 50 MB, Windows 약 33 MB → 약 35 MB 로 늘었습니다.

**보안 — 실행 파일에 포함된 라이브러리의 취약점 수정**

실행 파일에 포함되는 라이브러리를 같은 메이저 버전 안에서 보안 패치 버전으로 올렸습니다.

| 영역 | 라이브러리 | 수정된 문제 |
|---|---|---|
| 파일 업로드 (`file upload` · `cloud-auth zos-regist` · `cloud-auth recovery-regist`) | form-data 4.0.6 | 파일명에 줄바꿈 문자가 들어 있으면 업로드 요청에 임의의 헤더가 끼어들 수 있는 문제 |
| 로그 파일 회전 | moment 2.31.0 | 언어(locale) 이름 처리 중 파일 경로 조작 가능성 (CLI 는 이 값을 사용자에게서 받지 않아 실제 영향은 낮음) |

- 파일명은 이제 줄바꿈 문자가 인코딩되어 전송되며, 일반적인 파일명의 업로드 결과는 v3.0.0 과 같습니다.
- 그 밖에 대화형 입력 · 날짜 처리 · 옵션 파싱 라이브러리를 같은 메이저 안의 최신 패치로 갱신했습니다. 동작 변화는 없습니다.
