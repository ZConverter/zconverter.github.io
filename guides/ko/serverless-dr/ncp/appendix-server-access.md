## 6.1 서버 접속 방법

원격에서 Linux 서버에 SSH로 접속하는 방법을 설명합니다.

> 접속 대상은 Source ZDM 서버 또는 복구된 NCP 서버이며, 실제 서버의 IP 주소와 계정 정보를 사용합니다.

### 사전 조건

1. VM이 실행 중이고 SSH 서비스가 동작해야 합니다.

2. 접속 PC에서 VM의 IP 주소로 통신할 수 있어야 합니다.

(사설 IP만 사용하는 VM은 VPN 또는 경유 서버를 통해 접속합니다.)

3. 네트워크 방화벽과 VM 내부 방화벽에서 접속 PC의 TCP 22번 포트 접근을 허용해야 합니다.

4. VM의 IP 주소, 접속 계정, 비밀번호 또는 SSH 개인 키를 준비합니다.

### 접속 방법

터미널에서 인증 방식에 맞는 명령어를 실행합니다.

비밀번호로 접속:

`ssh -p 22 <계정명>@<VM_IP>`

SSH 개인 키로 접속:

`ssh -i <개인_키_경로> -p 22 <계정명>@<VM_IP>`

처음 접속할 때 호스트 키 확인 메시지가 표시되면 VM이 맞는지 확인한 후 `yes`를 입력합니다. 접속을 마치려면 `exit`를 입력합니다.
