1.  저장소에 저장된 백업 이미지 들을 클라우드 저장소(오브젝트 스토리지로) 동기화 기능을 사용할 수 있습니다.

2.  클라우드 저장소가 등록되어 있어야 해당 기능 사용이 가능합니다.

3.  업로드/다운로드/새로 고침/삭제 기능을 제공합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-04-01.png)

### 업로드

1.  저장소에 저장 되어있는 이미지들을 클라우드 저장소로 업로드 하는 기능입니다.

2.  업로드 하고자 하는 저장소의 관리부분의 작업 버튼을 클릭한 뒤 업로드를 클릭합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-04-02.png)

3.  업로드 하고자 하는 저장소를 선택합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-04-03.png)

4.  저장소를 선택하면 아래 화면과같이 업로드 옵션/업로드 옵션(고급) 부분이 나타나며  
    해당 부분을 선택 혹은 입력한 뒤 시작/등록 버튼을 클릭하여 작업을 진행합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-04-04.png)

5.  업로드 옵션

    1.  작업 명: 업로드 작업명을 입력하는 부분입니다.

    2.  폴더 명: 기존/신규

        1.  기존: 해당 클라우드 저장소에 이미 생성 되어있는 폴더명들이 나타나며 폴더명을 선택하여 해당 폴더명으로 업로드를 할 수 있습니다

        2.  신규: 해당 클라우드 저장소에 폴더를 생성하며 업로드 할 수 있는  
            기능입니다. 새로 생성할 폴더명을 입력합니다.

    3.  업로드 모드: 전체 업로드/증분 업로드

        1.  전체 업로드: 모든 파일을 업로드합니다.

        2.  증분 업로드: 변경된 파일만 업로드합니다. 최초 1회는 전체 업로드가  
            실행되고 그 이후에 변경된 파일만 업로드 됩니다.

    4.  스케줄: 필요 시 추가 버튼을 클릭하여 등록합니다.

6.  업로드 옵션(고급)

    1.  네트워크 제한(MB/s): 업로드시 네트워크 트래픽 조절 기능입니다.

    2.  파일명 필터: 업로드시 제외할 파일명 필터 기능입니다.

        1.  파일명 필터를 입력한 뒤 추가 버튼을 클릭하여 아래 리스트에  
            추가할 수 있습니다.

        2.  아래 리스트에서 추가된 파일명 필터를 클릭한 뒤 삭제 버튼을  
            이용하여 파일명 필터를 삭제할 수 있습니다.

1.  이후 모니터링 페이지로 자동으로 이동되며 해당 페이지에서 진행 상태를 확인할 수  
    있습니다.

### 다운로드

1.  클라우드 저장소에 업로드한 이미지들을 저장소로 다운로드 하는 기능입니다.

2.  다운로드 하고자 하는 저장소의 관리부분의 작업 버튼을 클릭한 뒤 다운로드를 클릭합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-04-05.png)

3.  다운로드 하고자 하는 저장소를 선택합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-04-06.png)

4.  저장소를 선택하면 아래 화면과같이 다운로드 옵션(기본)/다운로드 옵션(고급) 부분이 나타나며 해당 부분을 선택 혹은 입력한 뒤 시작/등록 버튼을 클릭하여 작업을 진행합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-04-07.png)

5.  다운로드 옵션(기본)

    1.  작업 명: 다운로드 작업명을 입력하는 부분입니다.

    2.  다운로드 모드: 증분/전체 다운로드

        1.  증분 다운로드: 선택한 저장소와 클라우드 저장소간 상이한 파일들만  
            다운로드 합니다.

        2.  전체 다운로드: 선택한 저장소의 데이터와 상관없이 전체 파일을 다운로드합니다. 파일이 덮어쓰기 될 수 있습니다.

    3.  다운로드 타입: 전체/특정 폴더만 다운로드

        1.  전체 다운로드: 선택한 저장소의 데이터와 상관없이 클라우드 저장소의  
            모든 폴더/파일을 다운로드합니다.

        2.  특정 폴더만 다운로드: 클라우드 저장소의 특정 폴더만 선택한 저장소로 다운로드합니다.

    4.  폴더: 특정 폴더만 다운로드 타입을 선택했을 때 활성화되며 선택 시 클라우드 저장소의 폴더 목록이 나타나며 다운로드 할 폴더를 선택합니다.

    5.  스케줄: 필요 시 추가 버튼을 클릭하여 등록합니다.

6.  다운로드 옵션(고급)

    1.  네트워크 제한(MB/s): 다운로드시 네트워크 트래픽 조절 기능입니다.

    2.  파일명 필터: 다운로드시 제외할 파일명 필터 기능입니다.

        1.  파일명 필터를 입력한 뒤 추가 버튼을 클릭하여 아래 리스트에 추가할 수 있습니다.

        2.  아래 리스트에서 추가된 파일명 필터를 클릭한 뒤 삭제 버튼을 이용하여 파일명 필터를 삭제할 수 있습니다.
