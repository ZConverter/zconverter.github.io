ZConverter 서비스를 이용하기 위해 라이선스 등록이 필요합니다.

라이선스 발급을 위해 ZDM의 UUID 값을 사용합니다.

### UUID 확인

1.  ZDM Web Portal에 접속합니다.([2.3 참고](/guides/ko/serverless-dr/ncp/web-access))

2.  **Management → ZDM** 메뉴로 이동합니다.

3.  대상 ZDM을 선택합니다.

4.  **UUID 값**을 확인합니다.

    예시 : ec258ffc-ea5c-37c2-d08c-57fd21538d8a

    ![](/assets/images/guides/serverless-dr-ncp/02-04-01.png)

### 라이선스 발급

확인한 UUID를 담당자에게 전달합니다.

담당자에게 라이선스 키를 전달받습니다.

예시 :

![](/assets/images/guides/serverless-dr-ncp/02-04-02.png)

### 라이선스 등록

1.  ZDM Web Portal에 접속합니다.

2.  **License 메뉴**로 이동합니다.

3.  **Add License** 버튼을 클릭합니다.

4.  발급받은 라이선스 키를 입력 후 등록합니다.

    ![](/assets/images/guides/serverless-dr-ncp/02-04-03.png)

    ![](/assets/images/guides/serverless-dr-ncp/02-04-04.png)
