1.  클라우드 저장소(오브젝트 스토리지)를 등록할 수 있습니다.

2.  저장소에 저장된 백업 이미지를 클라우드 저장소로 동기화 작업을 할 수 있습니다.

3.  클라우드 인증정보(오브젝트 스토리지)에서 인증정보를 등록해야 사용할 수 있습니다.

4.  클라우드 저장소 추가 방법

    1.  오브젝트 스토리지 추가 버튼을 클릭합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-03-01.png)

5.  등록된 클라우드 인증정보(오브젝트 스토리지)가 나타나며 클라우드 인증정보가 등록되지 않았을 때는 설정 페이지로 이동하라는 문구가 나타납니다.

6.  사용할 클라우드 키를 선택한 후 테스트 버튼을 클릭해서 유효한 파일인지 테스트를 시작합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-03-02.png)

7.  유효한 파일인지 검증이 완료되면 생성/등록을 이용하여 오브젝트 스토리지를  
    사용합니다.

    1.  생성

        1.  버킷 명을 입력하고 테스트 버튼을 클릭합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-03-03.png)

8.  사용 가능한 버킷 명인지 검증이 끝난 후 등록 버튼을 클릭하여 해당 버킷 명을 생성합니다. (단, 이미 존재하는 버킷명은 사용 불가능합니다.)

    ![](/assets/images/guides/serverless-dr-ncp/04-03-04.png)

9.  클라우드 저장소에 등록되었는지 확인한 후 해당 클라우드 저장소(오브젝트 스토리지)로 동기화 작업(업로드/다운로드)을 할 수 있습니다.

<!-- -->

1.  등록

    1.  클라우드 저장소의 버킷 목록들이 버킷 목록에 나타나며 서비스 센터에 등록할 버킷을 선택한 후 등록 버튼을 클릭합니다.

    ![](/assets/images/guides/serverless-dr-ncp/04-03-05.png)

2.  등록한 버킷을 확인한 후 해당 클라우드 저장소(오브젝트 스토리지)로  
    동기화작업(업로드/다운로드)을 할 수 있습니다.
